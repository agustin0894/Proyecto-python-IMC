#1.-Calculadora de Índice de Masa Corporal (IMC)

#https://github.com/agustin0894/Proyecto-python-IMC/blob/main/Calculadora%20del%20IMC%20Semana%204.py

#Este proyecto consiste en una calculadora del Índice de Masa Corporal (IMC) desarrollada en Python.
#El programa solicita al usuario su edad, peso y estatura. Después de recibir los datos, calcula el IMC mediante la fórmula:
#IMC = peso / estatura²
#El peso debe expresarse en kilogramos y la estatura en metros.
#El programa incorpora validaciones para evitar que los campos queden vacíos o que se introduzcan datos no numéricos en los campos correspondientes
#También comprueba que los valores ingresados sean mayores que cero.

#2. Tecnologías utilizadas

#Python.
#Visual Studio Code.

#3. Instrucciones de ejecución

Instalar Python en la computadora.
Descargar o clonar el repositorio del proyecto.
Abrir la carpeta del proyecto en Visual Studio Code.
Abrir una terminal en la carpeta donde se encuentra el archivo Python.
Ejecutar el comando
Seguir las instrucciones que aparecen en pantalla.
Introducir la edad, el peso en kilogramos y la estatura en metros.
